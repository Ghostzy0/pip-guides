# Set up Pip Guides

Build only editions included in this custom product. The default is Pip Core; Neutral Plus and Pip Plus are optional.

```sh
swift test
./scripts/build-app.sh pip
./scripts/build-app.sh baseline-enhanced
./scripts/build-app.sh pip-enhanced
```

Use the built-in sample practice window to check the synthetic workflow. External capture requires the user's native Screen Recording and Accessibility grants. Never bypass macOS consent or collect personal screenshots. Packages are locally ad-hoc signed and are not notarised. See [the edition map](EDITIONS.md).
